# 我的衣橱（网页版 · 可添加到 iPhone 主屏幕）

一个只管理**已经买到手的衣服和配饰**的个人衣橱。按品类、季节、色系整理，保存搭配，附上博主示范图或自己的穿搭照片；打开任意一件衣服就能看到“这件怎么穿”和可搭配的单品。

> **隐私说明**：放到 GitHub 上公开的只有 **App 的代码**（这个文件夹里的几个文件）。你拍的衣服照片、搭配等**所有数据都只保存在你自己的 iPhone 上**，不会上传到 GitHub，也不会上传到任何服务器。别人打开你的网址，看到的是一个空衣橱。

---

## 一、文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | App 本体（界面和全部功能） |
| `manifest.webmanifest` | 让 iPhone 识别为“可添加到主屏幕的 App”（名称、图标等） |
| `sw.js` | 离线缓存，让没有网络时也能打开 |
| `icons/` | 主屏幕图标 |
| `README.md` | 本说明 |

## 二、发布到网上（只需做一次，约 10 分钟）

### 1. 注册 / 登录 GitHub
打开 https://github.com ，注册或登录账号。记住你的**用户名**（下面用“用户名”代替）。

### 2. 新建一个仓库
1. 右上角 **＋** → **New repository**。
2. **Repository name** 填一个名字，例如 `wardrobe`（下面用“仓库名”代替，建议用英文小写）。
3. 选择 **Public（公开）**。
   - 免费账号的 GitHub Pages 需要仓库是公开的。再次说明：公开的只是代码，你的衣橱数据不在里面。
4. 其他选项不用管，点 **Create repository**。

### 3. 上传文件（两种方法任选一种）

**方法 A：网页上传（推荐，不需要任何工具）**
1. 在 Mac 上双击解压 `wardrobe-web.zip`，得到 `index.html`、`manifest.webmanifest`、`sw.js`、`README.md` 和 `icons` 文件夹。
2. 在刚建好的仓库页面，点 **Add file → Upload files**（如果是空仓库，点页面上的 “uploading an existing file” 链接）。
3. 把解压出来的**所有文件和 `icons` 文件夹**一起拖进网页（注意是拖文件本身，不要再套一层文件夹，`index.html` 必须在仓库最外层）。
4. 页面最下方点 **Commit changes**。
5. 上传后确认仓库首页能看到 `index.html`，并且有 `icons` 文件夹（点进去能看到几张 png 图片）。

**方法 B：用 Mac 的终端（会用 git 的话）**
```bash
cd 解压后的文件夹
git init
git add .
git commit -m "我的衣橱"
git branch -M main
git remote add origin https://github.com/用户名/仓库名.git
git push -u origin main
```

### 4. 开启 GitHub Pages
1. 在仓库页面点 **Settings（设置）** → 左侧 **Pages**。
2. **Source** 选 **Deploy from a branch**。
3. **Branch** 选 **main**，文件夹选 **/ (root)**，点 **Save**。
4. 等 1～2 分钟，刷新这个页面，顶部会显示网址：
   `https://用户名.github.io/仓库名/`

## 三、在 iPhone 上安装

1. 用 iPhone 的 **Safari** 打开 `https://用户名.github.io/仓库名/`（必须是 Safari，微信内置浏览器或其他 App 里打开不行）。
2. 点底部的 **分享** 按钮（方框加向上箭头）。
3. 往下滑，选 **添加到主屏幕**，名称保持“衣橱”，点 **添加**。
4. 以后都**从主屏幕的“衣橱”图标打开**，它会像普通 App 一样全屏显示，没网也能打开。

第一次打开是空衣橱。想先看看效果，可以点“先载入示例数据看看”，之后在右上角 **⋯ → 删除示例数据** 一键删掉。

## 四、数据保存在哪里？一定要看

- 数据保存在**这台 iPhone 上、主屏幕“衣橱”这个 App 里**。
- 注意：从主屏幕打开的“衣橱”和在 Safari 里直接打开的网页，**数据是分开的**。请固定从主屏幕图标使用。
- **删除主屏幕上的图标，可能会把数据一起删掉。**
- 在“设置 → Safari → 清除历史记录与网站数据”也可能清掉数据。
- iOS 可能会清理**长期不用的网站**的数据；添加到主屏幕后会大大降低这种风险，但仍建议定期备份。
- 换手机时数据**不会自动跟过去**（本版本没有 iCloud 同步），需要用下面的“备份/恢复”转移。

### 备份（强烈建议每 1～2 周一次）
1. 打开 App，右上角 **⋯ → 导出备份**。
2. 在弹出的分享面板里选 **存储到“文件”**（建议存到 iCloud 云盘里的某个文件夹），或者 AirDrop / 发送给自己。
3. 备份是一个 `.json` 文件，包含全部衣物、搭配和照片。
4. ⋯ 菜单里会显示“上次备份时间”；超过 14 天没备份，衣橱页顶部会提醒你。

### 恢复 / 换手机
1. 在新手机上按“三、在 iPhone 上安装”装好 App。
2. 打开 App，右上角 **⋯ → 导入备份**，在“文件”里选择之前导出的 `.json` 文件。
3. 确认后，App 里的数据会被**替换**为备份里的内容。

### 清空
右上角 **⋯ → 清空全部数据**（会二次确认，且无法撤销；清空前会建议你先导出备份）。

## 五、以后更新 App

1. 拿到新版本的文件后，按“方法 A”再上传一次（同名文件直接覆盖），点 **Commit changes**。
2. 等 1～2 分钟让 GitHub Pages 更新。
3. 在 iPhone 上打开“衣橱”，**关掉（上滑划掉）再打开一次**，有时需要重复两次才会换成新版本。可以在 **⋯ 菜单** 顶部看到当前版本号。
4. 更新 App **不会影响你的数据**（数据在手机上，不在 GitHub 上）。保险起见，更新前先导出一次备份。

## 六、常见问题

- **打开网址显示 404**：Pages 还没部署好，等几分钟；或检查 `index.html` 是否在仓库最外层、Pages 是否选了 main 和 / (root)。
- **图标显示不出来 / 是网页截图**：检查 `icons` 文件夹是否已上传；删除主屏幕图标前请先导出备份，再重新“添加到主屏幕”。
- **照片会不会很占空间**：拍照或导入的图片会自动压缩到最长边 1200 像素，一般一张几百 KB 以内。
- **能不能在电脑上用**：可以用浏览器打开同一网址，但电脑上的数据和手机上的是分开的（可以用导出/导入备份来转移）。
